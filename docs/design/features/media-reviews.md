# Media and reviews

## Purpose

Connect media context, feedback, revisions, and approval work.

## Anatomy

Project/collection navigation, search, list/grid toggle, media library, selected-project context, review queue, version status, comments, and revision actions.

## Behavior

Preserve media selection, collection filters, project context, review status, comments, revisions, and delivery/approval actions. Make the path from asset to timestamped note to assigned fix clear.

## States

Loading thumbnails, no media, no reviews, failed upload/load, permission-limited media, pending review, approved, and rejected/revision-needed.

## Responsive rules

Use a prioritized media list and selected-detail sheet. Keep search, approve/comment, and review status available on touch screens.

## Accessibility

Give thumbnails alt text or a useful title, expose version and review status as text, label media controls, and provide keyboard alternatives to drag/reorder.

## Preserved features

Media list/grid, collection filters, project context, feedback queue, review status, comments, and version actions.

## Acceptance checks

List/grid, search/filter, selection, review updates, mobile sheet, keyboard, contrast, and reduced-motion checks pass.
