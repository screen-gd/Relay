# Templates and resources

## Purpose

Reuse project setups and keep useful links close to work.

## Anatomy

Templates/resources tabs or contextual hub, search/filter, folders/collections, project links, create/edit/delete forms, copy/open actions, and blank-project flow.

## Behavior

Preserve template creation and blank projects, resource folders, project links, create/edit/delete/copy/open, and permission rules. Confirm destructive actions.

## States

Loading cards/rows, empty library, no results, duplicate link/template warning, save/delete errors, and read-only/sample mode.

## Responsive rules

Use compact cards/list and sheets for forms. Keep create and copy/open actions reachable without hover.

## Accessibility

Use links for navigation, buttons for actions, descriptive external-link labels, labeled forms, focus-managed dialogs, and text status cues.

## Preserved features

Resources, folders, project links, templates, blank-project flow, and CRUD actions.

## Acceptance checks

Create/edit/delete/copy/open, template-to-project, search, mobile form, keyboard, error recovery, and focus checks pass.
